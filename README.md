## Key Highlights & Performance Optimizations

<table width="100%">
<tr>
<td width="50%" valign="top">

### Rendering & Performance

- **GPU Acceleration:** WebGL GLSL shaders running on dedicated canvas context.
- **Route Code Splitting:** `React.lazy` + `Suspense` for asynchronous page chunk loading.
- **Animation Throttling:** `requestAnimationFrame` throttled mouse listeners preventing layout thrashing.
- **Memoization Strategy:** Strategic `React.memo` and `useCallback` implementations.
- **Compositor Transforms:** High-performance CSS transforms (`translateZ(0)`) maintaining fluid 60 FPS.

</td>
<td width="50%" valign="top">

### Design & Interaction System

- **Bespoke Cursor Mechanics:** Custom spring-physics cursor with contextual hover state labels.
- **Dynamic 3D Card Tilt:** Perspective rotation on project cards calculated dynamically on `mousemove`.
- **Spotlight Hover Effect:** Radial light spotlight tracking cursor movement across cards.
- **Glassmorphism Navigation:** Floating header bar featuring high-density backdrop blur.
- **Leather & Gold Tokens:** Pure CSS diamond texture matched with aged gold (`#c9a96e`) accents.

</td>
</tr>
</table>

## Getting Started

```bash
# 1. Clone repository
git clone https://github.com/mananjani2102/Portfolio.git

# 2. Change directory
cd Portfolio

# 3. Install dependencies
npm install

# 4. Launch local development server
npm run dev
```

Application will run locally at `http://localhost:5173`.
